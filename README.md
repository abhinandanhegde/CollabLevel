# CollabLevel

**CollabLevel is a platform that helps people discover collaborators, work together on projects, and build professional credibility.**

## How It Works

1. **Create a Profile** — Add your skills, interests, industry, and portfolio.
2. **Discover** — Find brands, creators, agencies, and professionals.
3. **Connect** — Send and accept connection requests.
4. **Collaborate** — Propose projects with goals, deliverables, deadlines, and compensation details.
5. **Track Progress** — Manage milestones and confirm project completion.
6. **Review** — Participants can review each other after completing a collaboration.
7. **Build Credibility** — Earn a credibility score based on your professional activity.

## Credibility Score

The credibility score is calculated out of **100 points**:

- Completed Collaborations: **40 points**
- Reviews: **30 points**
- Profile Completeness: **15 points**
- Responsiveness: **15 points**

Scores are calculated from database records and updated when relevant activity changes.

## Technology Stack

- **Lovable** — Application development
- **Supabase** — Backend services and authentication
- **PostgreSQL** — Database for profiles, connections, collaborations, milestones, and reviews
- **Row Level Security (RLS)** — Helps protect data and restrict access to authorized users

## Key Features

- Professional profiles and discovery
- Connection requests
- Collaboration proposals and milestone tracking
- Completion confirmation by both participants
- Reviews and credibility scoring
- Database-backed data persistence

## Project Goal

**CollabLevel transforms professional networking into meaningful collaborations and helps users build credibility through completed work and feedback.**
